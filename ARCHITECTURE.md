# Arsitektur Proyek MVC

## Struktur Folder

- models : menyimpan data dan logika database
- views : menangani tampilan aplikasi
- controllers : penghubung model dan view
- assets : menyimpan file statis seperti gambar, CSS, dan JavaScript

## Pola Arsitektur

Project menggunakan pola MVC (Model View Controller) untuk memisahkan:
- logika data
- tampilan
- kontrol aplikasi

Tujuannya agar project lebih rapi, mudah dikembangkan, dan memudahkan kolaborasi tim.
